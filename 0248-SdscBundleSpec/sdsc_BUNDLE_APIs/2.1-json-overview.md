# Overview — SDSC Bundle JSON Schema API

This document describes the JSON structure for SDSC Bundle format as defined in `sdscbundle-schema.json`. This schema covers only fields described in [sdscbundle-schema.json](sdscbundle-schema.json). Furthermore, the aforementioned schema follows the JSON standard as described in [JSON Schema](https://json-schema.org/learn/getting-started-step-by-step). The structure is based on [draft 2020-12](https://json-schema.org/draft/2020-12).

**Important**: This schema represents what the **frontend (torch-spyre)** is allowed to produce to drive the **backend (DeepTools)**.

## Schema Validation Resources

Several python based tools are available to validate the schema as well as any json file created by any tool that follows the aforementioned schema.

1. **[`validate_schemas.py`](../json_schema/validate_schemas.py)** — Validates that JSON Schema files are valid schemas
2. **[`check_sdsc_json_files.py`](check_sdsc_json_files.py)** — Validates SDSC JSON data files against a schema

## Installation

```bash
pip install jsonschema
```

## Schema validation

Validates that JSON Schema definition files are correctly formatted and comply with JSON Schema Draft 2020-12 specification.

### When to Use

- After creating or modifying a schema file
- To verify schema syntax before using it for validation
- To check multiple schema files at once

### Usage

Validate a Single Schema:

```bash
python validate_schemas.py sdscbundle-schema.json
```

Validate Multiple Schemas:

```bash
python validate_schemas.py custom-schema.json sdscbundle-schema.json
```

### Example Output

```
Validating 2 schema file(s):

✓ custom-schema.json is a valid JSON Schema Draft 2020-12
  Title: deepTools JSON Schema
  Version: 1.2.1
  Description: Complete JSON Schema for deepTools format

✓ sdscbundle-schema.json is a valid JSON Schema Draft 2020-12
  Title: SDSC Bundle JSON Schema
  Version: 1.0.1
  Description: JSON Schema for SDSC Bundle format

Summary:
  Total schemas: 2
  Valid: 2
  Invalid: 0

✓ All schemas are valid!
```

### Exit Codes

- `0`: All schemas are valid
- `1`: One or more schemas are invalid

## JSON file validation

Validates SDSC JSON data files (e.g., generated by torch-spyre) against the JSON Schema defined in [`sdscbundle-schema.json`](sdscbundle-schema.json) or [`custom-schema.json`](../json_schema/custom-schema.json).

### When to Use

- After generating SDSC files from torch-spyre
- To verify SDSC files conform to the expected format
- In CI/CD pipelines to catch format issues
- Before importing SDSC files into deeptools

### Usage

Basic Validation:

```bash
# Validate a single file
python check_sdsc_json_files.py examples/sdsc_0.json

# Validate multiple files
python check_sdsc_json_files.py examples/*.json
```

Options:

- `-v, --verbose`: Show detailed error information including schema paths
- `-s, --schema PATH`: Use a custom schema file (default: sdscbundle-schema.json)
- `--no-color`: Disable colored output

Advanced Examples:

```bash
# Verbose output with detailed error information
python check_sdsc_json_files.py -v examples/sdsc_0.json

# Use deeptools schema instead of sdscbundle schema
python check_sdsc_json_files.py --schema custom-schema.json examples/sdsc_0.json

# Validate all example files
python check_sdsc_json_files.py examples/*.json

# Validate with no color (for CI/CD)
python check_sdsc_json_files.py --no-color examples/*.json
```

### Example Output

```
Loading schema: sdscbundle-schema.json
✓ Schema is valid

Validating 3 file(s):

✓ sdsc_0.json - Valid

✓ sdscExp.json - Valid

✗ sdscBroken.json - Invalid
  Path: exp -> dscs_ -> 0 -> exp -> numCoresUsed_
  Error: 'numCoresUsed_' is a required property

Summary:
  Total files: 3
  Valid: 2
  Invalid: 1
```

### Exit Codes

- `0`: All files are valid
- `1`: One or more files failed validation or schema/file loading errors
