# Key Differences from Backend Schema

This schema (`sdscbundle-schema.json`) represents the **frontend** (torch-spyre) format. Key differences from the backend (Deeptools) schema include:

1. **Root Structure**: Pattern property with operation name, not "sdsc" key
2. **Field Names**: Uses torch-spyre conventions (e.g., `dsName_` not `label_`)
3. **Data Types**: Uses torch-spyre enums (e.g., `dsType_`: "INPUT"/"OUTPUT"/"KERNEL"/"KERNEL_IDX")
4. **Memory Components**: Lowercase "hbm"/"lx" not "HBM"/"LX"
5. **Schedule Tree**: ScheduleTreeNode structure, not AllocateNode
6. **Data Formats**: SEN169_* formats, not DL16/FP32/FP8/INT8/INT4
